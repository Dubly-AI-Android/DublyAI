## 🎙️ What is Dubly AI?

**Dubly AI** is an Android application for **real-time AI video dubbing and audio translation** powered by **Google Gemini Live**.

It is designed to translate supported video playback audio while the video is playing, without requiring users to upload the complete video file first.

The basic workflow is:

**Play a video → Start Dubly AI → Select a target language → Listen to the translated audio**

Dubly AI can be useful for foreign-language videos, tutorials, educational content, online videos, streaming content, and other supported Android playback sources.

## 🧠 Google Gemini Live

Dubly AI uses Google's Gemini Live technology for real-time audio translation.

The application connects directly to the Gemini service using the user's own Gemini API key.

A Gemini API key is required to use the live dubbing functionality.

### Get a Gemini API Key

Create or manage a Gemini API key through Google AI Studio:

**https://aistudio.google.com/apikey**

> Google API usage, quotas, availability, and any applicable charges are controlled by Google and are separate from the Dubly AI application.

---

## 🔑 API Key Privacy

Dubly AI is designed so that users provide their own Gemini API key.

The key is stored locally on the Android device using Android security mechanisms rather than being provided through a shared Dubly server.

Dubly AI does not require a dedicated audio relay server for the Gemini connection.

## 🎬 How to Use

### 1. Install Dubly AI

Download and install the latest APK from the Release section.

### 2. Add Your Gemini API Key

Open Dubly AI and enter your Gemini API key.

The application can test the connection before saving the key.

### 3. Play a Video

Open a supported video or media application and start playback.

### 4. Start Dubbing

Open Dubly AI, select the desired target language, and start the dubbing session.

### 5. Listen

Dubly AI captures supported playback audio, sends it to Gemini Live for translation, and plays the translated audio back on the device.

## 🛠️ Troubleshooting

### No translated audio

Try:

1. Check your Gemini API key.
2. Test the API connection in the application.
3. Check your Internet connection.
4. Make sure the source application permits playback capture.
5. Try headphones.
6. Try another Dub Output Route in Settings.
7. Restart the dubbing session.

### Gemini connection problems

Check:

- API key validity
- Internet connectivity
- Google Gemini API availability
- Your Google API quota and account status

### Audio is captured but cannot be heard

Try changing the **Dub Output Route** in Settings. Android devices and manufacturers can handle multiple audio streams differently.
